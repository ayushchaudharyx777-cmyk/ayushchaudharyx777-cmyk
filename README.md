### 🚀 Featured Projects

#### 🤖 J.A.R.V.I.S — Personal AI Assistant

A fully custom Python-powered personal AI assistant — not a wrapper around an API, but a real desktop system built piece by piece from scratch. Runs on a **local LLM (Ollama)** for offline, private AI responses. Full voice interaction, animated custom GUI, and a complete productivity dashboard built in.

<details>
  <summary><b>🛠️ View Technical Features & Integrations</b></summary>
  <br>
  <ul>
    <li>🖥️ Custom GUI with <b>CustomTkinter</b> — animated startup sequence, cinematic dark aesthetic with particle effects.</li>
    <li>🧩 Local LLM via <b>Ollama (llama3.2)</b> — fully offline, zero API costs, private.</li>
    <li>🗣️ Voice I/O via <b>speech recognition</b> + <b>pyttsx3 / ElevenLabs</b> TTS.</li>
    <li>🎵 Optional integrations: <b>Spotify</b>, <b>OpenCV</b> (webcam), <b>Flask</b> (LAN server), <b>librosa</b> (voice emotion analysis).</li>
    <li>⚙️ 15+ built-in tools: Pomodoro, clipboard manager, code executor, habit tracker, unit converter, QR/password generator, network scanner, screenshot OCR, process killer, weather alerts, CPU/RAM monitor, hotkey overlay.</li>
  </ul>
</details>

#### 🏎️ Redline Labs — F1 Engine Room Simulator

A single-file HTML/CSS/JS F1 racing simulator featuring 10 F1 teams with 2025/2026 data, animated SVG cars, particle systems, ghost lap system, track selector, pit stop simulator, team radio popup, drag race mode, and live race standings.
